# 数据出处与版本

8张样例均为用户提供的项目PDF页面导出图。它们混合图解、表格、照片和界面，source_kind为project_page。
文件名、页码、阶段见data/assets.json。素材作者归属暂标团队项目，不推定每张均由用户独立制作。
页面含实物照片时，只能证明该页有相应图像；它不是原照片、原视频或可运行工程。

T1版本：2025年第一学期气候响应与模块装置。
T2版本：2026-03-24第二学期竹构+网格壳体；含植物行为和光照/距离响应。
本包12个生成任务只以T2竹构网壳为结构版本，不与最终弹性网布版本混合。

measurements.csv：T2期末第22—25页，4个行为状态，每状态14个参数，共56条观测记录，统一为米。
C/R/H/D各符号的准确含义以原图为准，当前使用原参数名，避免猜测。
prepared_on是此次整理日期，presentation_date是汇报日期，原测量日期未知。

所有review_status从unreviewed开始，评分和reviewer为空。12个生成任务status为planned、result_asset_ids为空。
AI生成任务只有在真实产出导回后才可记为generated，人审之后才可记为reviewed。

后续做训练数据时，需要另外筛原始图像、核对使用权限、去重、保留来源和标签，不能把整页图直接等同优质训练集。

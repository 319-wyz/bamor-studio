# 手工验收

先记录测试日期、浏览器和版本，每项写通过/失败/未测。不要提前全部勾选。

## M1
- 首次打开能解释用途，有样例导入入口。
- 导入样例后恰有8份，重复导入不会变16份。
- 上传一张真实图片，可预览和编辑标签。
- 不支持格式或无法读图时提示具体原因。
- 搜索词和多个筛选组合正确，空结果能清除筛选。
- 选择2份并排比较，可移除、替换或取消。
- 为一份标记通过，一份标记淘汰并写原因，初始评分保持空值。
- 刷新后元数据、标签和新增图片仍在；改变浏览器后的本地范围限制有说明。
- CSV导出仅包含约定范围，中文正常、引号/逗号/换行字段正确。
- JSON备份能按实际承诺恢复，ID与图片不串配；无恢复功能时不得标“备份恢复完成”。

## M2 自然语言AI选图
- 未配置服务端密钥时明确显示“未配置模型密钥”，提交按钮禁用，不产生模拟推荐。
- 浏览器端、HTML、前端JavaScript和导出文件中不包含API密钥。
- 真实调用时，服务端请求包含候选素材的实际图片输入；返回ID全部属于本次候选，不重复、不遗漏说明。
- 推荐包含排序、任务作用、可见依据、需求关系和不确定项；其余候选有本次不推荐原因。
- 学期、来源等事实与元数据一致；重量、性能等无法从图片确认的信息不被编造。
- “选择作品封面”与“解释网格壳体构型”分别真实调用，推荐与理由能随用途变化；记录模型、响应ID和图片数量。
- AI建议与人工确认均可在刷新后恢复，人工确认不会改变素材已有审核状态和人工理由。

## M3 设计素材生产自动化
- 2份真实素材均能导出所选比例，像素尺寸准确。
- 等比放入，不拉伸，不误裁实验说明，标题不溢出。
- 对比板与预览一致，画布图像加载失败时有反馈。
- 文件命名、素材ID、模板和清单逐项对应。
- 实际完成一次“筛选—标注—批量输出—检查清单”的完整任务，保留录屏。

## M4 生成任务组织
- 12个计划任务没有被当成12张已生成图片。
- 提示词包含T2版本与结构约束，手动复制可用。
- 导回一张真实结果后，任务与结果ID匹配，平台/模型/时间按实际填写。
- 结果仍可不通过，审核原因可编辑，未审核不进入通过数量。

# 用真实任务测量

先自测功能，再邀请确实做视觉素材的同学试用；人数与结果按实际记录。
不要在没有测量时填提效百分比，不把现在的试用写成过去的用户访谈。

建议任务：
1. 从同一批素材找到指定版本的3份图，写取舍理由。
2. 使用同样标题和信息，制作一张2图对比板。
3. 输出规定比例的素材卡，并给出对应来源清单。

对比人工方法与工具方法，保持输入、任务和质量要求相同。
记录开始/结束、有效耗时、顺序、对任务熟悉程度、是否返工。
质量记录：任务完成/未完成，缺图、重复、错名、来源缺失、标签丢失等。
如果由自己连续做两次，第二次有熟悉效应，应如实解释；有条件交换任务顺序。

效率改善=(人工耗时-工具耗时)/人工耗时。只有任务等价、质量要求达标时再解释这个数。
素材通过率=通过审核的独立素材数/已审核的独立素材数，未审核不进入分母。
导出完整率=实际完整导出的规定项/计划导出的规定项。明确“项”是素材、图片文件还是清单行。

# 人工审美与一致性标签 v0.1

用途：建立可解释、可复核的人工取舍。不是自动结构安全分析。
样例页图也可以评价，但应说明评价对象是页面表达；后续AI单图应另标content_type。

四个维度均可按1—5分评价，未评价留null。不要自动填默认3分。
- 构型一致性：是否保留参考版本的主体数量、连接和结构关系。
- 材料表达：竹材/网壳的视觉表达是否清晰，是否与要求冲突。
- 场景适配：尺度、人物活动与场景要求是否一致。
- 视觉清晰度：主体、构图、遮挡和信息是否清楚。

通用尺度：1明显不满足；2多处问题；3基本可用但需修改；4满足主要要求且表达清晰；5满足要求且细节完整。
标签需结合具体对象写备注。各维度独立，不把视觉好看当作构型正确。

审核状态：unreviewed/approved/rejected。
淘汰原因可多选：结构关系失真、材料不一致、场景尺度不符、主体遮挡、画面不清、重复、信息不足、其他。
保留reviewer、reviewed_at、rubric_version和文字原因，允许修改并记录版本。
这套量表是本次新增的工具设计，尚不是原项目历史执行过的审美打标。
